##Phase Diagrams for Magrathea v2: A planetary interior modeling platform in C++ submitted to JOSS##

Planets on each plot are 1 Earth-mass with 100% of the mass in the layer of the diagram (hydrosphere, mantle, mantle (with carbon phase diagram)).

For mode0.cfg set all masses to 0.0, all temp_jump parameters to 0, and surface_temp to desired temperature for each line. 

For first panel: mass_of_hydro=1.0. 

For second panel: mass_of_mantle=1.0, mass_of_hydro=1.0. 

For third panel: mass_of_mantle=1.0, mass_of_hydro=1.0, mantle_phasedgm="C_simple".
